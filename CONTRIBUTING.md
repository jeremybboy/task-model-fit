# Contributing

Use a feature branch and a draft PR. Explain the task, changed behavior,
validation evidence, and remaining limitations. Run the offline checks documented
in `docs/testing.md`. Do not make authenticated model requests in CI.

The owner reviews and merges PRs. Agents never merge or enable auto-merge, and
must never push directly to the default branch after the initial scaffold.
Stage explicit paths and preserve unrelated work.

Do not commit credentials, local run data, screenshots with account information,
or original handoff material. A public source repository does not authorize
publishing someone else's task inputs or model outputs.
